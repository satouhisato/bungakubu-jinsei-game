# 文学部人生ゲーム

机の上に置いたノートパソコンで全員が順位とポイントを大画面で確認し、ゲームマスター（オーナー）がスマホから得点を操作するステータス管理Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 机置きノートPC向け「超特大表示 ＆ 1画面フィット」
- **スクロールバー一切なし**: 一般的なノートPCの画面に2×2の4人分がピッタリ収まります。
- **超特大ポイント数字**: 全体画面から操作ボタンを省いたことで、数字が超特大（`text-8xl` 等）で中央に堂々と表示され、遠くからでも一目瞭然です。
- **現在の順位バッジ**: 各プレイヤー枠に `🥇 1位` `🥈 2位` `🥉 3位` `4位` のバッジを常時表示。
- **ヘッダーランキングバー**: 画面最上部にも全員の順位・点数サマリーが表示されます。
- **キーボード矢印キー操作**: `←` `→` `↑` `↓` でプレイヤー枠を移動選択、`Enter` で拡大表示、`Esc` で4分割に戻る。

### 2. 👑 マスター用QR（スマホ得点操作コントローラー）
- 画面右上の「マスター用QR」ボタンからQRコードを表示。
- オーナーがスマホで読み取ると、**「全プレイヤーの得点を操作できるマスターコントローラー」**が起動します。
- スマホからプレイヤー（P1〜P4）を切り替えて、`10〜100` の増減ボタン（加算・減算）を押すと、**机の上のノートPC（4分割画面）がリアルタイムに瞬時に連動して動きます**。

### 3. 📱 プレイヤー用QR（閲覧専用・手元確認）
- 各プレイヤー枠の「閲覧QR」ボタンからQRコードを表示。
- 各プレイヤーがスマホで読み取ると、**編集ボタンが一切ない「閲覧専用画面」**が開き、自分の順位やりてらポイント、全体のランキングを手元で確認できます。
