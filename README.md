# 文学部人生ゲーム - ステータス管理ボード

机の上にノートPCを置いて複数人で囲みながら遊ぶシチュエーションに完全特化した、ステータス管理・可視化Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 机置きノートPCに最適化されたUI
- **1画面ぴったり収容**: スクロールバーが一切出ず、一般的なノートPC（1366x768 / フルHD）の画面に2×2の4人分がすっきりと収まります。
- **超特大のりてらポイント数字**: 机の向かい側や少し離れた場所からでも、誰のポイントが何点かパッと瞬時に見えます。
- **柔らかいフォント（Zen Maru Gothic）**: 温かみのある丸みフォントで統一。

### 2. りてらポイント一本化 ＆ 10〜100増減
- 初期値は `0` ポイント。
- `+10, +20, +30, ..., +100` および `-10, -20, ..., -100` までワンタップで加減算可能。
- `＋ 加算` / `− 減算` の切り替えトグル付きで押し間違いを防止。
- キーボードからの直接数値入力も可能。

### 3. キーボード操作（矢印キー移動）
- 4分割画面時、キーボードの **`←` `→` `↑` `↓`** キーでプレイヤー枠間を移動可能（発光ハイライト表示）。
- **`Enter`** で選択中のプレイヤーを大画面拡大。
- 拡大画面時、**`←` `→`** で前後のプレイヤーへ切り替え、**`Esc`** で4分割に戻る。

### 4. 📱 プレイヤー用QRコード（閲覧専用・手元確認）
- 各プレイヤー枠の「閲覧QR」ボタンを押すと、そのプレイヤー専用のQRコードが表示されます。
- スマホのカメラで読み取ると、**編集機能のない「閲覧専用画面」**が開き、自分のりてらポイントや獲得カードを手元でじっくり確認できます（誤操作や不正の心配がありません）。

### 5. 👑 マスター用QRコード（オーナー専用 スマホ得点操作）
- 画面右上の「マスター用QR」ボタンを押すと、オーナー専用のQRコードが表示されます。
- オーナーがスマホで読み取ると、**「全プレイヤーの得点を操作できるマスターコントローラー」**が起動します。
- スマホからプレイヤーを切り替えて、得点の増減（`10〜100`）やカード付与を手元で行うと、**机の上のノートPCの4分割画面がリアルタイムに瞬時に連動して動きます**。
