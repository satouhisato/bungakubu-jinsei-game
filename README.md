# 文学部人生ゲーム - ステータス管理ボード

文学部人生ゲーム用のステータス管理・可視化Webアプリケーションです。

## 主な機能
1. **4分割画面 (2×2 グリッド)**:
   - 4人プレイ（プレイヤー1〜4）の「りてらポイント」「学びポイント」「所持カード数」を一目で一覧表示。
   - プレイヤー名をクリックしていつでも変更可能。
2. **個別拡大ビュー (フォーカスモード)**:
   - 任意のプレイヤー枠の「拡大」ボタンをクリックすると、大画面でステータスやカード操作が可能。
   - 「4分割画面に戻る」ボタンでいつでも全体画面へ復帰。
3. **直感的なポイント入力**:
   - **キーボード直接入力**: 数値欄に直接入力して即時反映。
   - **ワンクリック増減**: `+10, +20, +30, +40, +50` ボタン（減算マイナスボタンも完備）。
   - **アニメーションゲージバー**: ポイントに応じて滑らかにバーが伸縮。
4. **マス獲得カード管理**:
   - マスに止まった際に獲得したカード（カード名、効果/メモ、タイプ）を登録。
   - 所持カードの手札一覧表示、使用済みチェック、削除。
   - カード獲得時には華やかなファンファーレ音＆紙吹雪演出！
5. **URLで共有・リアルタイム同期**:
   - 「URLで同期・共有」ボタンを押して発行されたURLを他の人のPCやスマホに送るだけで、同じゲーム画面がリアルタイムに連動します（WebRTC P2P通信）。
6. **自動保存**:
   - ブラウザのLocalStorageに常時自動保存されるため、誤ってブラウザを閉じたり再読み込みしてもデータが失われません。
